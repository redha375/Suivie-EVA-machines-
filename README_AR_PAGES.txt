CTP SMART — نسخة PWA تجريبية منشورة على GitHub Pages

الموقع المنشور
- الرابط: https://redha375.github.io/Suivie-EVA-machines-/
- هذه نسخة تجريبية ميدانية؛ لم تُفعّل مزامنة Supabase أو النسخ الاحتياطي إلى Dropbox.

التثبيت على الهاتف بعد النشر عبر HTTPS
- Android: افتح الرابط في Chrome ثم القائمة ← تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
- iPhone/iPad: افتح الرابط في Safari ثم مشاركة ← إضافة إلى الشاشة الرئيسية.
- افتح التطبيق مرة واحدة مع الإنترنت لتحميل الموارد؛ بعدها تُخزَّن ملفات الواجهة للعمل دون اتصال.

حدود مهمة
- هذه واجهة تجريبية عامة منشورة على GitHub Pages. سجلاتها تبقى في تخزين المتصفح على الجهاز نفسه، ولا توجد مزامنة بين الأجهزة أو نسخ احتياطي إلى Dropbox.
- لا يوجد خادم أو قاعدة إنتاج في الحزمة؛ OCR عبر الخادم، سجلات التدقيق المركزية وأي ميزة تتطلب API لن تعمل على GitHub Pages.
- لا تدخل بيانات مصنع حقيقية أو حساسة. مسح بيانات المتصفح أو إزالة التطبيق قد يفقد البيانات المحلية.
- ليست هذه حزمة APK؛ إنها PWA تُثبَّت من موقع HTTPS.
